Architectures used in this project

Architecture choice matters because it changes the exact update rule: how neighbor signals are aggregated, how self-information is mixed in, and what structural distinctions survive through depth.

GCN

GCN uses degree-normalized aggregation. This usually gives stable optimization and smooth representations, but normalization can dampen raw counting signals. That is one reason GCN can struggle on tasks where exact local counts are central.

GraphSAGE

GraphSAGE was designed as an inductive "sample-and-aggregate" architecture: instead of learning one embedding per training node, it learns an update function that can be applied to unseen nodes (and even unseen graphs with compatible features). At each layer, it aggregates neighbor information, combines it with the node's own current state, and passes the result through a learnable transform.

Its main practical strength is scalability on large or evolving graphs via neighborhood sampling, while still preserving local structure. In this project, the SAGEConv layers use aggr="add", so neighbor messages are summed. That choice helps retain count-like signals and aligned well with degree prediction in the experiments.

GIN

GIN also uses sum aggregation, but then applies an MLP with a learnable self-weight term. That extra nonlinearity makes it one of the strongest 1-WL-style architectures for structural discrimination.

1-WL refers to the one-dimensional Weisfeiler-Lehman refinement procedure, a standard baseline for graph distinguishability.

Loopy (r-lMPNN style)

Loopy adds a second structural channel on top of ordinary message passing. Standard MPNNs aggregate from direct neighbors; Loopy also looks at short paths/cycles around each center node, so it can model how neighbors are connected to each other, not only to the center. Intuitively, the node receives messages about local "loop shape," not just local degree.

Concretely, preprocessing builds r-neighborhood path sets, and each layer processes those paths by length and pools them back to center nodes. In this repository, those path tensors are loopyN*/loopyA*; the Loopy layer runs a path-wise convolution and then scatter-sums contributions back to node states. This is the mechanism behind the cycle sensitivity.

Theoretical motivation from the r-loopy WL / r-loopy MPNN line is that this family can count cycles up to length r+2, extending what plain 1-WL-style message passing can capture.
