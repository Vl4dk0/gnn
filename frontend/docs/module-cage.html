Cage generation: the main objective

This is the end goal of the thesis. Prediction tasks were preparation; here I focus on constructing valid (k,g)-graphs.

Why I started with an A* idea

The initial plan was not to replace search, but to guide it. I wanted a search procedure that proposes many candidates and a learned guider that tells which branches should be explored and which should be dropped when the branching factor explodes.

In code, the A* part is best-first search over partial graph states. It hashes states, skips duplicates, and pushes high-score successors into a priority queue: 

# ai/cage/functions/astar.py
for succ_graph in successors:
    graph_h = graph_hash(succ_graph)
    if graph_h in self.visited_hashes:
        self.duplicates_skipped += 1
        continue
    self.visited_hashes.add(graph_h)
    succ_score = self._score_graph(succ_graph)
    heapq.heappush(self.pq, (-succ_score, self.counter, succ_graph))

What went wrong with the guided-A* dataset idea

The bottleneck was data quality. I needed strong positive and negative examples of partial states, especially states near the real decision boundary: not trivially good and not trivially hopeless.

It is similar to fitting a separator between red and blue points: the most informative points are near the separating line. If those are missing or badly distributed, the learned guide becomes unstable. Building a reliable dataset of those hard boundary cases became a rabbit hole.

Why I switched to PPO

I switched from guide-for-A* to an explicit agent policy. The agent acts on unordered node pairs: if an edge is absent it can try to add it; if present it can try to remove it. The environment keeps active nodes connected and enforces degree/girth constraints through action validity checks.

Current reward constants in code are: ADD_REWARD = +0.1, REMOVE_PENALTY = -0.2, INVALID_PENALTY = -0.05, SATISFY_BONUS = +0.1 when an action preserves or reaches a target property, and SUCCESS_REWARD = +20.0 when both regularity and girth targets are satisfied. 

# ai/cage/rl/env.py (constants)
SUCCESS_REWARD = 20.0
INVALID_PENALTY = -0.05
ADD_REWARD = 0.1
