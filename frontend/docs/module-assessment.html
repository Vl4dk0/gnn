Assessment across degree and min-cycle

This page compares both prediction tasks together, because success on only one task is not enough to claim broad structural understanding.

Snapshot conclusion

As of 2026-02-23, no single model in these experiments performs best on both tasks at once. Degree prediction is strongest with SAGE/GIN, while min-cycle prediction is strongest with Loopy(r=3).

This statement is intentionally timestamped, because it can change after larger models, longer training, or different data regimes.
