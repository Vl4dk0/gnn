Graph neural networks for algebraic graph theory

The core thesis question is: can learning help us construct new (k,g)-cage graphs? Before models and metrics, I need the language to be precise.

What do these terms mean?

A graph is k-regular when every vertex has exactly k neighbors. If k=3, every vertex must have degree 3, no exceptions. The girth of a graph is the length of its shortest cycle. So if the smallest loop has 5 edges, girth is 5.

A (k,g)-graph is simply a graph that satisfies both conditions at once: it is k-regular and has girth g. A (k,g)-cage is the smallest possible graph that satisfies those two constraints.

Why this is hard

For example, if I were to generate k-regular graph, I would just create complete graph of k+1 vertices. This is generally simple for any k.

If I were to generate graphs with girth g, I would just create a cycle of length g. This is also generally simple for any g.

But combine those two with the minimum-size requirement, and the task becomes a hard combinatorial search problem in practice. Exact cage orders are still unknown for most (k,g) pairs. Notice that I used a clear trick for each single constraint; maybe there is an analogous trick for (k,g)-graphs, but I do not know it yet. One hope is that GNN-guided search can help expose such structure.
