How GNNs work in this project

Here I explain the mechanism directly: how the model reads structure through message passing and why that matters for degree prediction, cycle prediction, and cage guidance.

Message passing in plain technical language

A node updates its embedding by combining its own current state with aggregated information from neighbors. The aggregation is permutation-invariant, which means node ordering does not matter. Stack more layers, and each node can use a larger neighborhood.

In MPNN (Message Passing Neural Network) form:

h v (t+1) = Ut ( h v t , ∑ w∈N(v) Mt ( hvt , hwt , evw ) )

This abstraction is exactly what my models implement in different architectural ways.
