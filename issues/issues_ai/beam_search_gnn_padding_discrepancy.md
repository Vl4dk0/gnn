# Issue: Discrepancy Between Training Data and Beam Search Inference for GirthPredictor (Padding with Zero)

## Severity
Medium / High (Degrades GNN guidance quality in beam search)

## Description
In `ai/cage/voltage/search.py`, `beam_search` assigns voltages to base graph edges incrementally. At each step, it scores candidates by padding unassigned edges with `0` and passing them to the GNN-based `GirthPredictor`:
```python
                    # Pad remaining edges with 0 for model input
                    full_volts = extended + [0] * (m - len(extended))

                    data = base_graph_to_pyg(
                        base, full_volts, group, k, g_target, girth=0
                    )
```
However, this approach introduces two significant issues:
1. **Ambiguity of 0**: In the group representation, `0` represents the group's identity element. The model cannot distinguish between an edge explicitly assigned the identity element and an unassigned edge.
2. **Out-of-Distribution Inputs**: The `GirthPredictor` is trained in `ai/cage/voltage/train.py` using datasets generated by `generate_dataset` (in `ai/cage/voltage/data_gen.py`), which consist entirely of **fully assigned** voltage lists:
```python
        n_edges = base.num_undirected_edges()
        volt = [rng.randint(0, group.order - 1) for _ in range(n_edges)]
```
The GirthPredictor is never trained on partially assigned graphs or graphs with padded zeros. During beam search inference, it is queried on partial graphs, leading to out-of-distribution inputs and highly unreliable heuristic scores.

Unlike `VoltageAssignmentEnv` (used in RL training), which explicitly includes an `assigned` feature flag (1.0 vs 0.0) for edge features to indicate assignment status, `GirthPredictor` has no such indicator.

## Location
`ai/cage/voltage/search.py` (lines 304-314) and `ai/cage/voltage/data_gen.py`

## Proposed Fix
Two possible solutions:
1. **Incorporate assignment flags in GirthPredictor**: Modify `base_graph_to_pyg` and `GirthPredictor` to accept an edge feature matrix containing both the voltage value (or embedding) and an `assigned` flag (0 or 1), similar to how `VoltageAssignmentEnv` represents state.
2. **Train with Partial/Padded Graphs**: Mix partially assigned graphs (with random stages of completion) into the training dataset for `GirthPredictor` so it learns to predict potential girth from partial assignments.
